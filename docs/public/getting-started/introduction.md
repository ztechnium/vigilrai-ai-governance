# Introduction

The community edition is a runtime governance console for one organization, powered by [Ztechnium](https://ztechnium.com). It sits between your agents and the business systems they act on, and it enforces policy before an action proceeds.

There is no hosted signup and no second organization. You sign in to the instance you run.

## What this edition does

- **Registers** AI systems, agents, versions, and their dependencies
- **Authorizes** tool calls and consequential actions against policy
- **Enforces** allow, deny, and approval decisions with fail-closed defaults
- **Observes** agent trajectories and keeps evidence
- **Reports** risk, budget, and portfolio posture for this instance
- **Invites** teammates into departments and governance roles

## Who it is for

- **Platform engineers** integrating governance into agent infrastructure
- **Governance teams** defining policy and reviewing evidence
- **Security teams** requiring runtime enforcement and an audit trail

## Core principle

Governance happens before the action, not only afterward. RAI intercepts a tool or model call before it reaches a downstream system and keeps a receipt of the decision.
